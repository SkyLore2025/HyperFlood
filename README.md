# HyperFlood V13

Stable V12 plus Layer 07: Explainable Flood Pressure Integration.

V13 introduces no new external data service. It combines the existing terrain, soil/runoff, mapped river/drainage proximity, recent NASA precipitation and forecast precipitation layers into a transparent 0–100 prototype pressure index. NASA historical trends remain long-term Earth-system context and are intentionally not treated as short-term flood forcing.

The integrated index is a screening signal, not a calibrated flood probability or official warning. Layer 08 remains reserved for the final 24h / 48h / 7-day early-warning outlook.
